# 🌌 Glowing Night Flowers

> A serene, bioluminescent floral animation built for the browser using pure HTML, CSS, and JavaScript.

![Glowing Night Flowers Preview](image_2f461f.jpg)

## ✨ Features

* **Zero Dependencies:** Built entirely with vanilla HTML5, CSS3, and JavaScript—no external frameworks or libraries needed.
* **Bioluminescent Aesthetics:** Uses CSS gradients, `box-shadow` glow effects, and keyframe animations to create soft cyan blossoms and floating fireflies against a dark night sky.
* **Smooth Organic Motion:** Animates swaying grass blades, blooming petals, and drifting light particles.
